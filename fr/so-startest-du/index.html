Smartphone et objet connecté

Vous profitez de toutes les fonctionnalités de l’application si vous utilisez, en plus de votre smartphone, un objet connecté comme l’Apple Watch. Notre application fonctionne aussi avec les bracelets d’activité ou montres connectées d’autres fabricants, à condition qu’ils se synchronisent avec Apple Santé. Si vous n’avez pas encore d’objet connecté, vous pouvez voir ici quels appareils ont été bien notés par Stiftung Warentest (en allemand). Les bracelets d’activité simples coûtent à partir d’environ 40 €.

Démarrez en quatre étapes simples :

ÉtapeCe que vous faites
01 TéléchargerTéléchargez d’abord actiself depuis l’App Store d’Apple. Si vous utilisez une Apple Watch, l’application watchOS s’installe automatiquement.
02 S’inscrireInscrivez-vous ensuite dans l’application avec une adresse e-mail et un mot de passe. Nous utilisons votre adresse e-mail uniquement pour communiquer avec vous dans le cadre de l’utilisation de l’application. Le mot de passe doit comporter au moins 8 caractères (majuscules, minuscules, un chiffre et un caractère spécial).
03 VérifierAprès l’inscription, vous recevez un code à votre adresse e-mail. Saisissez-le afin que votre adresse e-mail puisse être vérifiée.
04 ActiverÀ l’étape suivante, un code d’activation vous est demandé. Vous pouvez l’acheter sur notre boutique. Après votre achat, vous recevez un e-mail avec votre code d’activation. Saisissez-le – et c’est parti !
